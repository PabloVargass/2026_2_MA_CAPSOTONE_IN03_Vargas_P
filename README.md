Proyecto APT de Pablo Vargas Vásquez · Ingeniería en Informática · Duoc UC Maipú · Sección IN03.

## Estructura

```text
Fase 1/
  Evidencias Individuales/   1.1 Autoevaluación de competencias, 1.2 Diario de reflexión
  Evidencias Grupales/       Presentación Proyecto.pptx, 1.5 Guía Definición Proyecto APT (Español)
Fase 2/
  Evidencias Individuales/   2.1 Diario de reflexión, 2.2 Autoevaluación de avance
  Evidencias Grupales/       2.3 Formativa, 2.4 Guía Desarrollo Proyecto APT, 2.6 Guía Informe Final (Español), Informe Final ServiciosYa (.docx y .pdf)
  Evidencias Proyecto/
    Presentación Proyecto.pptx
    Fichas de Iteración/            Fichas de avance 1 a 6 y planilla de evaluación económica
    Evidencias de documentación/    Casos de uso, interfaces, modelo de datos, modelo 4+1 (vistas lógica, desarrollo, procesos, física y escenarios), diagramas e informe técnico
    Evidencias de sistema/
      Aplicación/                   App móvil, página web de administración y capturas
      Base de datos/                Esquema Prisma, migraciones y backend
Fase 3/
  Evidencias Individuales/   Pendiente (3.1 Diario de reflexión)
  Evidencias Grupales/       Bitácora semana 15, mini presentación; pendiente la presentación final
```

| Carpeta | Contenido |
|---|---|
| `ServiciosYa/` | Código vigente del sistema: `backend/` (API NestJS), `mobile/` (app Expo), `web-admin/` (panel Next.js) y `apk/` (instalador Android) |
| `Fase 1/`, `Fase 2/`, `Fase 3/` | Documentación y evidencias de cada fase; las versiones en `Evidencias de sistema` son copias fijas |
| `render.yaml` | Configuración del despliegue de la API en Render |
